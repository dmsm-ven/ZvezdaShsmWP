# Инструкция по управлению сайтом

Это краткое руководство поможет самостоятельно менять тексты, фотографии, расписание и другие материалы сайта через WordPress. Редактировать код сайта для обычных обновлений не нужно.

**Вход в админку:** `http://localhost:8080/wp-admin/` (после переноса сайта используйте его постоянный адрес).

## Как редактировать страницы сайта

1. Войдите в WordPress под своей учётной записью.
2. Откройте сайт и перейдите на нужную страницу через меню в шапке.
3. В верхней панели нажмите **«Редактировать страницу»**.
4. Измените нужные поля и нажмите **«Обновить»**.

Так можно открыть страницы «О клубе», «Философия», «Тренеры», «Расписание», «Медиа», «Полезное», «Оплата» и «Контакты». Ссылка редактирования в верхней панели видна только авторизованным пользователям.

На странице редактирования найдите блоки с названием соответствующего раздела. Обычно для изменения содержимого достаточно заменить текст или изображение и сохранить страницу.

## Общие настройки клуба

**Где найти:** в админке откройте **Настройки клуба**.

Здесь находятся данные, которые используются в разных местах сайта:

- Название клуба и логотип.
- Телефон, email и физический адрес.
- Ссылки на VK, Telegram, YouTube и отзывы.
- Ссылка для встраивания карты.
- Короткое описание в подвале сайта.
- Срок, в течение которого закрытый посетителем верхний баннер не показывается повторно.

Измените нужные значения и сохраните настройки. Контакты и ссылки обновятся во всех блоках сайта, где используются общие настройки.

**Карта:** вставляйте именно ссылку для встраивания карты (URL из атрибута `src` iframe), а не обычную ссылку на место или маршрут.

## Главная страница

Откройте главную страницу сайта и нажмите в верхней панели **«Редактировать страницу»**. Основные настройки собраны в блоках с префиксом **«Главная —»**.

| Блок | Что можно изменить |
|---|---|
| Верхняя полоса | Текст объявления |
| Баннер | Фоновое изображение, заголовок, подзаголовок, описание и три факта |
| Статистика | Четыре значения и поясняющих текста |
| Возрастные группы | Заголовок и описание четырёх групп |
| Преимущества | Заголовки и описания шести преимуществ |
| Фотогалерея | Три фотографии и ALT-тексты |
| Расписание и стоимость | Дни и время тренировок, тарифы, цены и состав абонемента |
| Видео | Заголовок, описание, ссылка на YouTube и превью |
| Запись | Заголовок, описание и фотография блока заявки |

Несколько важных особенностей:

- **Тренеры** на главной выбираются из раздела «Тренеры». Показываются не более двух опубликованных тренеров с включённой настройкой «Отображать на главной».
- **Расписание и тарифы** общие для главной, страницы «Расписание» и страницы «Оплата». Меняйте их только в блоке «Главная — Расписание и стоимость».
- **Видео** на странице «Медиа» использует те же настройки, что и видеоблок главной страницы.
- Поля формы заявки настраиваются отдельно в разделе **Контакт → Контактные формы**. Не удаляйте форму и не меняйте её ID без согласования.
- Некоторые подписи, заголовки и шаги записи заданы в шаблоне сайта и не редактируются через поля. Для их изменения обратитесь к специалисту.

## Тренеры

Откройте в админке раздел **Тренеры**.

Чтобы добавить тренера, нажмите **«Добавить тренера»** и заполните:

- ФИО.
- Общее описание и опыт.
- Фотографию (изображение записи).
- Титулы и должности.
- Переключатель **«Отображать на главной»**, если тренер должен появиться на главной странице.

В блоке «Титулы и должности» нажимайте **«Добавить титул»**, чтобы добавить отдельные строки. На сайте они объединяются через точку-разделитель.

Порядок карточек задаётся числом в поле **«Порядок»**: меньшее значение выводится выше. Чтобы временно скрыть тренера, переведите запись в черновик.

## Статьи раздела «Полезное»

Откройте **Записи → Добавить новую**.

1. Укажите заголовок и добавьте текст статьи.
2. При необходимости добавьте изображения, заголовки и списки.
3. Установите **Изображение записи** — это обложка карточки.
4. При желании заполните поле **Отрывок** — краткое описание для карточки.
5. Нажмите **«Опубликовать»**.

Для изменения статьи откройте **Записи → Все записи** и выберите нужную. На странице «Полезное» отображаются опубликованные записи, новые — выше старых. Чтобы временно скрыть материал, переведите его в черновик.

## Вопросы и ответы

Откройте раздел **Вопросы и ответы**.

Добавьте вопрос через **«Добавить вопрос»**: заголовок записи — это сам вопрос, а ответ указывается в поле **«Ответ»**. Сохраните запись кнопкой **«Опубликовать»**. Для изменения откройте существующий вопрос и нажмите **«Обновить»**. Временно скрыть вопрос можно, переведя его в черновик.

## Отзывы

Откройте раздел **Отзывы** и нажмите **«Добавить отзыв»**.

Для каждого отзыва можно указать:

- Текст отзыва.
- Имя автора.
- Источник (например, Яндекс.Карты).
- Дату отзыва.

После заполнения нажмите **«Опубликовать»**. Для изменения выберите отзыв в списке и нажмите **«Обновить»**. Порядок задаётся полем **«Порядок»**. Чтобы временно убрать отзыв с сайта, переведите его в черновик.

## Изображения

При выборе изображения можно использовать уже загруженный файл из медиатеки или добавить новый через вкладку **«Загрузить файлы»**.

Рекомендации:

- Для баннеров выбирайте качественные горизонтальные фотографии.
- Для тренеров используйте портреты, на которых хорошо видно лицо.
- Не загружайте повторно изображения, которые уже есть в медиатеке.
- По возможности заполняйте ALT-текст — короткое описание фотографии.
- Не удаляйте файлы из медиатеки, пока не убедитесь, что они больше нигде не используются.

## После редактирования

- Для существующей страницы или записи нажмите **«Обновить»**, для новой — **«Опубликовать»**.
- Откройте страницу сайта и проверьте результат, в том числе на телефоне.
- Если изменения не появились, обновите страницу с очисткой кэша браузера. При наличии плагина кэширования очистите и его кэш.

**Важно:** не удаляйте страницы и не меняйте настройки шаблонов без согласования. Если нужного поля нет в редакторе, возможно, этот элемент задан непосредственно в шаблоне сайта — обратитесь к специалисту.
